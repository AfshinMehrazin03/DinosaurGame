# 🦖 Dinosaur Game

بازی دایناسور دونده شبیه بازی گوگل کروم با منوی شروع و پایان

## فایل‌ها
- `MainMenu.cs` - منوی اصلی با دکمه‌های Start و Quit
- `DinoController.cs` - کنترل حرکت و پرش دایناسور
- `ObstacleMovement.cs` - حرکت موانع
- `ObstacleSpawner.cs` - تولید موانع
- `ScoreManager.cs` - امتیاز و بهترین امتیاز
- `GameManager.cs` - مدیریت وضعیت بازی

## نحوه بازی
- **Space**: پرش
- از کاکتوس‌ها عبور کن
- بهترین امتیاز ذخیره میشه

## صحنه‌های مورد نیاز
- MainMenu (منوی اصلی)
- GameScene (صحنه بازی)
